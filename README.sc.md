# 精简二次曲线转换 1.0

作者：Zonz。将三次贝塞尔曲线转换为控制点较少的二次曲线。适用于 Glyphs 3 的 Python 3 环境，支持 Intel 与 Apple Silicon，无额外 Python 依赖。

## 安装与使用

解压后双击 CubicToQuadratic.glyphsPlugin 安装，替换旧版并重启 Glyphs。

在「路径」菜单选择「转换为精简的二次曲线」，快捷键为 ⇧⌘2。按住 Option 显示设置入口，快捷键为 ⇧⌥⌘2。

编辑视图中，选中三次曲线的两个控制点或两个端点可转换指定曲线；没有节点选择时处理当前字形。字体视图中处理选中的字形。

兼容主版与相关特殊图层同步转换，保持一致的节点结构。组件保留引用，其基础字形也可能被转换。选中的备份或背景图层独立处理，不改动其他图层或组件基础字形。

## 设置

有效改动立即保存。数字框支持方向键增减，按住 Shift 可加快调整。按 Tab 切换设置项，按空格切换复选框。

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 轮廓拟合容差 | 1（单位于一千全宽细分度） | 控制转换后的轮廓与原轮廓允许相差的程度。较小的值更贴近原形，较大的值更容易减少控制点。 |
| 控制点数量上限 | 3 | 限制每个转换结果最多使用的控制点数，接受任意正整数。较小的上限有利于精简，但可能降低拟合精度。 |
| 尝试居中贴线控制点范围 | 7（单位于一千全宽细分度） | 当结果只有一个控制点，且该点靠近两端点的连线时，尝试将它向居中位置调整，同时控制轮廓变化；设为 0 可关闭。 |
| 视为平滑连接的角度容差 | 5° | 判断相邻曲线是否可视为平滑连接，用于连接方向保持及曲线合并。数值越大，允许的原始方向差异越大。 |
| 维持平滑的直线连接处 | 开启 | 在曲线与直线原本平滑连接的位置保持切线方向，减少转换后连接处出现折角的情况。 |
| 维持平滑的曲线连接处 | 开启 | 保留原曲线连接点时，按两侧原切线的平均方向保持平滑连接；关闭合并或合并失败时也生效。 |
| 尝试合并平滑连接的曲线 | 开启 | 尝试将相邻的平滑曲线一起拟合，减少原有连接锚点；无法在容差内合并时保留连接并分别转换。 |
| 在控制点间加入锚点 | 关闭 | 在相邻二次曲线控制点之间加入显式锚点，便于直接选择和编辑；关闭时使用隐含中点。 |
| 以整数座标转换 | 开启 | 直接在整数网格上寻找拟合控制点，同时考虑轮廓与连接方向，原有端点座标保持不变。 |

距离按字体 UPM 自动换算，使不同全宽细分度的字体使用一致的设置尺度。

## 注意事项

达到控制点数量上限后不再增加点数，普通转换可能超出拟合容差。合并仅在容差内进行，不跨越直线、既有二次曲线、选择边界或受 hint 保护的连接点。

原有端点座标保持不变。不兼容的字形或无法满足约束的转换不会强行写入。

转换支持取消，完成后可一次撤销。界面支持简繁中文、英语、日语、韩语、德语、法语、西班牙语、意大利语、葡萄牙语及俄语，跟随 Glyphs 的语言。

ConvertToCompactQuadratic.py 为同步备用脚本，顶部常量独立于插件设置。源代码见 development；许可见 THIRD-PARTY.md 与 GlyphsSDK-LICENSE.txt。
