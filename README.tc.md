# Cubic To Compact Quadratic

將三次貝塞爾曲線轉換為控制點更少和質量更好的二次曲線。適用於 Glyphs 3 的 Python 3 環境，支援 Intel 與 Apple Silicon，無額外 Python 相依套件。

## 安裝與使用

解壓縮後按兩下 CubicToCompactQuadratic.glyphsPlugin 安裝，取代舊版並重新啟動 Glyphs。

在「路徑」選單選擇「轉換為精簡的二次曲線」，快速鍵為 ⇧⌘2。按住 Option 顯示設定入口，快速鍵為 ⇧⌥⌘2。可在 Glyphs 設定中自定義快捷鍵。

編輯檢視中，選取三次曲線的兩個控制點或兩個端點可轉換指定曲線；沒有節點選取時處理目前字形。字型檢視中處理選取的字形。

相容主版與相關特殊圖層同步轉換，保持一致的節點結構。組件保留參照，其基礎字形也可能被轉換。選取的備份或背景圖層獨立處理，不改動其他圖層或組件基礎字形。

## 設定

| 選項 | 預設值 | 說明 |
| --- | --- | --- |
| 輪廓擬合容差 | 1（單位於一千全寬細分度） | 控制轉換後的輪廓與原輪廓允許相差的程度。較小的值更貼近原形，較大的值更容易減少控制點。 |
| 控制點數量上限 | 3 | 限制每個轉換結果最多使用的控制點數，接受任意正整數。較小的上限有利於精簡，但可能降低擬合精度。 |
| 嘗試居中貼線控制點範圍 | 7（單位於一千全寬細分度） | 當結果只有一個控制點，且該點靠近兩端點的連線時，嘗試將它向居中位置調整，同時控制輪廓變化；設為 0 可關閉。 |
| 視為平滑連接的角度容差 | 5° | 判斷相鄰曲線是否可視為平滑連接，用於連接方向保持及曲線合併。數值越大，允許的原始方向差異越大。 |
| 維持平滑的直線連接處 | 開啟 | 在曲線與直線原本平滑連接的位置保持切線方向，減少轉換後連接處出現折角的情況。 |
| 維持平滑的曲線連接處 | 開啟 | 保留原曲線連接點時，按兩側原切線的平均方向保持平滑連接；關閉合併或合併失敗時也生效。 |
| 嘗試合併平滑連接的曲線 | 開啟 | 嘗試將相鄰的平滑曲線一起擬合，減少原有連接錨點；無法在容差內合併或連接點受 hint 保護時保留連接並分別轉換。 |
| 在控制點間加入錨點 | 關閉 | 在相鄰二次曲線控制點之間加入顯式錨點，便於直接選取和編輯；關閉時使用隱含中點。 |
| 以整數座標轉換 | 開啟 | 直接在整數網格上尋找擬合控制點，同時考慮輪廓與連接方向，原有端點座標保持不變。 |

## 注意事項

轉換支援取消，完成後可一次還原。介面支援簡繁中文、英語、日語、韓語、德語、法語、西班牙語、義大利語、葡萄牙語及俄語，跟隨 Glyphs 的語言。
