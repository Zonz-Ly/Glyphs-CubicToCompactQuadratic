# 第二輪算法審查

依據 `CubicToCompactQuadratic_algorithm_review_tests/` 的第二輪文件，基準提交為 `7d8eb1923d8aac6759013ca6c354181b20ce017e`。11 個來源模組均已核對 Git blob SHA。原審查目錄保持不變；以下記錄本地代碼修改與驗證。

## 精度要求

不使用達到容差就接受簡單候選的路徑，不減少搜尋起點、目標函數採樣數或迭代預算，不放寬切線、格點、幾何平坦化與最終連續誤差驗證。先修正評分與可行性錯誤，再以修正後版本作為效能優化的對照，以免將錯誤評分下的結果當成精度基準。

## 第一批：三項正確性修正

- 弧長採樣在折線區間內以有括區間的 Newton／二分反求曲線參數，普通與複合 Context 共用。幾何平直不再被誤當成參數速度均勻。單調直線投影使用同一反求；點曲線保留有限結果。
- 一般最近點保留原有全部候選。Newton 分母非正、未收斂或停在內部括區間邊界時，增加三次曲線距離導數（至多五次式）的駐點候選，以導數分區及二分求根回退。收斂時採用最後一步，並保留該步前的候選。既有二次曲線最近點的三次求根算法沒有更換。
- 分割候選只捕捉 `TangentConflict`，記為不可用並繼續搜尋；跳過不可達後綴與不可行的封閉旋轉。只有所有完整分割不可行才回報衝突，取消與其他錯誤仍向外傳遞。
- 一個控制點的兩條切線只有非平行唯一交點才省去搜尋；重合平行射線在兩者公共區間內做一維最佳化，每次候選同時保留兩端限制。

提供的三項回歸測試修正前出現三次 assertion failure 與一次 error，修正後全部通過。另將三項重現及 11 項邊界測試納入 `development/test_review_round2.py`，涵蓋反向／旋轉／縮放直線、均勻幾何採樣、複合採樣、失敗 Newton、迴圈與反向行進、點曲線、平行射線公共區間、不可達後綴、封閉旋轉、全部不可行及取消傳遞。

第一批完整測試：263 項通過，見 `correctness-tests.txt`。外掛入口使用 mock Glyphs / AppKit；未在原生 Glyphs 中測試整套字型。

## 第二批：保留精度的效能優化

效能對照為第一批正確性提交 `e6794956e3d6d9f0bc18ededba47bddebaba29dd`，而非仍含評分錯誤的 `7d8eb19`。

- 每次目標函數評分預建各段二次曲線控制點包圍盒。查詢按距離下界遞增訪問，僅在下界扣除浮點餘量仍嚴格大於已有距離時停止求根；距離相等仍優先採用原索引較小的曲線。餘量同時考慮控制點與查詢點尺度。正向與反向採樣數、權重及 Jacobian 保持不變。
- 合併結果只有一個浮點控制點、且兩條精確非平行射線已有唯一可行交點時，略過無約束搜尋。結果繼續走原調整及原誤差驗證。此路徑不讀寫以 `normal, count` 為鍵的無約束解快取；整數、平行與多控制點案例保留原搜尋。
- 保留二次曲線最近點的原三次求根算法、運算順序、括區間及停止條件，僅重用分隔節點值並展開內層回呼。重用已計算的二次／三次曲線候選位置與距離，預算來源曲線不變差分及點曲線判斷；為二／三次平坦化展開相同順序的 de Casteljau 步驟，一般階數保留原路徑。
- 補充近乎平行射線的邊界防護：公共區間解碼後仍按現有 `on_ray` 規則核對兩條射線，避免浮點平行判斷容差下的遠距候選違反另一端限制。不放寬切線條件。

新增第二批 10 項測試，包含 20,000 組剪枝與逐段求根的完整 `(距離, 參數, 索引)` 相等對照、同距離索引順序、遠距查詢餘量、實際省去求根、合併唯一解不建立 Context、不污染無約束快取、整數／平行模式保留搜尋、不可行交點及近乎平行射線的雙重約束。第二輪共 24 項測試，連同原有測試 **273 項全部通過**，見 `final-tests.txt`。

`verify_review_round2.py` 獨立從第一批 Git 提交載入原函式，再逐項核對修改後回傳值：50,004 組根列表、10,000 組二次最近點、1,200 組來源最近點、12 批來源樣本及 300 組平坦化點列與誤差界限完全相等，見 `exact-checks.json`。這些是針對性測試，並非對全部浮點輸入的形式化證明。

## 重跑

在項目根目錄執行：

```sh
python3 -B build.py
python3 -B -m unittest discover -s development -q
python3 -B CubicToCompactQuadratic_algorithm_review_tests/test_regressions.py development
python3 -B development/verify_review_round2.py --reference e679495 --output /tmp/cubic-r2-exact.json
mkdir -p /tmp/cubic-r2-correctness
# 使用完整本地 Git 歷史匯出正確性基準。
git archive e679495 | tar -x -C /tmp/cubic-r2-correctness
python3 -B development/benchmark_review_round2.py --reference-dir /tmp/cubic-r2-correctness --output /tmp/cubic-r2-benchmark.json
```

原審查的效能原型使用函式原始碼字串替換並修改程序內函式，適用於其審查版本；改寫後應使用本輪新增的精確對照與測速工具。
